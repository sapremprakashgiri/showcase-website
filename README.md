# ShowCase — Dark Premium Product Website

## Files
- index.html — homepage, featured products and catalog
- product.html — product details, gallery, specifications and reviews
- style.css — dark premium responsive design
- script.js — product data, search/filter, wishlist and reviews

## Run in VS Code
1. Open this folder in VS Code.
2. Open `index.html`.
3. Right-click the file and choose **Open with Live Server** if you have the Live Server extension.
4. You can also double-click `index.html` and open it directly in a browser.

## Features
- Dark premium responsive UI
- Product catalog
- Search products
- Category filtering
- Product detail pages
- Image gallery
- Wishlist using localStorage
- Customer review submission using localStorage
- Responsive mobile layout

Internet is required for the demo product images and Google font.
